# NGD Academy — نسخة مطوّرة من التصميم الأصلي

هذه النسخة مبنية على ملفات الموقع الأصلي المرفوع، مع الحفاظ على شكل الصفحة الرئيسية وألوان الهوية، وإزالة بوابة الطالب/الإدارة والاعتماد على Supabase.

## التغييرات
- الحفاظ على الصفحة الرئيسية والتصميم الحاليين قدر الإمكان.
- إزالة `auth.html` ومجلدي `student/` و`admin/` وملفات `supabase/`.
- إضافة `config/site-config.js` لإعداد روابط Google Forms.
- تعديل صفحة التطوع لتستخدم رابط Google Form من الإعدادات.
- إضافة بداية Google Apps Script لإنشاء جداول عامة للكورسات والإعلانات والفعاليات.

## إعداد رابط استمارة التطوع
افتح `config/site-config.js` وأضف رابط الاستمارة:
`volunteerForm: "ضع_رابط_استمارة_التطوع_هنا"`
يمكنك إضافة رابط تسجيل الكورسات إلى `courseRegistrationForm` لاحقًا.

## إعداد Google Sheets وApps Script
1. أنشئ Google Sheet جديدًا لحساب الأكاديمية.
2. افتح Extensions > Apps Script.
3. انسخ محتوى `apps-script/Code.gs`.
4. شغّل `setupNGDSheets()` مرة واحدة.
5. أضف بيانات الكورسات والإعلانات والفعاليات في الأوراق المناسبة.
6. عند الحاجة لعرض بيانات الجداول داخل الموقع، ننفذ ربط الواجهة بالـ Web App في خطوة منفصلة بعد تجهيز البيانات وروابط النماذج.

## ملاحظات
- Google Forms تظل خيار التسجيل الأساسي؛ اربط ردود النماذج بـ Google Sheets من إعدادات Forms.
- لا تضع بيانات شخصية للطلاب في جداول منشورة للعامة.
- هذه النسخة لا تحتوي تسجيل دخول أو درجات أو حضور أو بيانات طالب خاصة.
- لا تحذف النسخة القديمة من جهازك إلا بعد تجربة هذه النسخة.
